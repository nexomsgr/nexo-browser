# Nexo Browser

Лёгкий браузер для Windows 10/11 x64 на Rust + Wry + Microsoft Edge WebView2.
Главный приоритет — реальная экономия RAM. Любые преимущества над Chrome/Brave
подтверждаются только измерениями (см. `bench/`, появится на шаге 8).

## Структура

```
src/
  main.rs            точка входа
  app.rs             цикл событий, команды
  browser/           вкладки, WebView2, навигация, popups
  memory/            политики режимов, усыпление, монитор ресурсов
  ui/                тема и интерфейс
  storage/           SQLite
  downloads.rs  permissions.rs  shortcuts.rs
  internal_pages/    nexo://performance и др.
```

## Сборка (на Windows)

```
cargo build --release
```
Результат: `target\release\nexo.exe`. Нужен установленный WebView2 Runtime
(есть в Windows 11 и в актуальной Windows 10).


## Система экономии памяти (шаг 5)

* `nexo://performance` — реальные метрики: Working Set и Private Bytes всего дерева процессов
  (Toolhelp + `GetProcessMemoryInfo`), CPU (`GetProcessTimes`), число процессов, состояние вкладок.
  Если замер недоступен (не Windows) — страница показывает причину, а не числа.
* Smart Tab Sleeping: каждые 10/15/30 с (по режиму) `sleeper::plan` выбирает вкладки; перед сном
  страница опрашивается на несохранённый ввод; фоновые вкладки со звуком, загрузкой, вводом или
  загрузкой страницы не усыпляются. Этапы: `TrySuspend` → выгрузка WebView2 (теряется история
  «назад/вперёд» этой вкладки; адрес и заголовок сохраняются).
* Режимы: «Экономия памяти» (30 с / 5 мин / ≤4 живых вкладок, `MemoryUsageTargetLevel=Low` для скрытых,
  `--process-per-site` — экспериментально), «Сбалансированный» (2 мин / 15 мин / ≤10), «Максимальная
  производительность» (10 мин / 60 мин / без лимита). Аргументы WebView2 применяются только при запуске.
* Не проверено на Windows: всё, что вызывает WebView2 (TrySuspend, IsDocumentPlayingAudio, уровень
  памяти, process-per-site). Проверка — шаги 7–8.

## Основные функции (шаг 6)

* Горячие клавиши (`shortcuts.rs`, одна таблица): из панели интерфейса — через пересылку `key`;
  из страницы сайта — через `AcceleratorKeyPressed` WebView2 (только Windows). Перехватываются лишь
  клавиши из таблицы. Ctrl+T/W/Shift+T/L/R/Tab/1–9, Ctrl+±/0, F11, Ctrl+D, Ctrl+H и др.
* Масштаб по вкладке (ступени 25–500 %), хранится в сессии. Ctrl+колесо WebView2 меняет масштаб сам,
  но эти изменения приложение не отслеживает.
* Полноэкранный режим: F11 и полноэкранный режим из страницы (видео); панель скрывается.
* Закладки (звёздочка, папки), история (поиск, удаление), загрузки (реальный прогресс через
  `DownloadOperation`), настройки — внутренние страницы `nexo://bookmarks|history|downloads|settings`.
* Сессия: сохраняется при каждом изменении; при запуске загружается только активная вкладка,
  остальные выгружены до первого открытия.
* Приватное окно (Ctrl+Shift+N): отдельный процесс `nexo.exe --private`, временный профиль WebView2,
  база только в памяти, профиль удаляется при закрытии.
* Не сделано / ограничения: своё окно разрешений сайтов (работает встроенный запрос WebView2, `permissions.rs`
  пока не подключён), выбор папки загрузок, масштаб по сайтам, обновление в обход кэша (Ctrl+Shift+R = обычное).


## Внешний вид в стиле Chrome/Brave

* Панель вкладок и панель инструментов вплотную, активная вкладка сливается с панелью адреса; адресная строка — скруглённая «таблетка».
* Меню ⋮ (справа): новая/приватная вкладка, закладки, история, загрузки, масштаб − / + , печать, полный экран, производительность, «Освободить память», настройки, выход. Закрывается по Esc, клику вне меню, смене вкладки и изменению размера окна.
* Меню — отдельный WebView2, который создаётся при открытии и уничтожается при закрытии (так оно всегда над страницей и не занимает память в закрытом виде).
* Значок вкладки — буква заголовка (favicon не загружаются — экономия памяти и трафика).
* Новая вкладка: поиск и плитки самых посещаемых сайтов из локальной истории.
* Проверено: сборка/тесты/clippy на Linux, вёрстка и отправляемые сообщения — в headless Chrome. НЕ проверено на Windows: поведение оверлея меню (фокус/закрытие по клику вне, размер) — проверяется в CI-сборке и вручную.

## Перенос данных и менеджер паролей

**Перенос между устройствами (JSON).** Настройки → «Перенос данных». Экспорт сохраняет закладки (с папками), историю и настройки в `nexo-backup-<дата>.json` в папке «Загрузки». На втором устройстве — «Импорт»: данные сливаются с текущими (ничего не удаляется, повторы пропускаются; настройки применяются только по галочке; путь загрузок не переносится). Файл проверяется как недоверенный: только http/https-адреса, защита от циклов папок, лимит 32 МБ.

**Менеджер паролей (`nexo://passwords`, пункт «Пароли» в меню ⋮).**
* Мастер-пароль (минимум 8 символов) → ключ Argon2id (19 МиБ, 2 прохода) → AES-256-GCM, у каждой записи свой nonce. На диске только шифртекст (тест это проверяет). Мастер-пароль нигде не хранится; забытый — не восстановить, можно лишь удалить хранилище.
* Автоблокировка через 10 минут без действий; при блокировке ключ и пароли стираются из памяти. Пароли отправляются странице только по запросу («Показать», «Пароль», «Изменить»).
* Добавление, изменение, удаление, поиск, генератор паролей (crypto.getRandomValues), смена мастер-пароля.
* **CSV:** импорт понимает Chrome/Brave/Edge, Firefox, Bitwarden (по названиям столбцов), дубликаты пропускаются; экспорт — формат Chrome (`name,url,username,password,note`), требует повторного ввода мастер-пароля и предупреждает, что файл содержит пароли открытым текстом. В приватном окне менеджер недоступен.
* Автоподстановка паролей в формы на сайтах и предложение «сохранить пароль» пока НЕ реализованы.

Файлы импорта читает сама страница и передаёт в Rust кусками (лимит одного сообщения 128 КБ, для остальных команд — 8 КБ). Экспорт пишется в «Загрузки» без перезаписи существующих файлов.

Проверено: unit-тесты (шифрование, неверный пароль, подмена данных, смена мастер-пароля, CSV-разбор, JSON-перенос, враждебные файлы), поведение страницы в headless Chrome с имитацией Rust. НЕ проверено на Windows: реальный запуск, скорость Argon2 в релизной сборке (opt-level "z"), чтение файла через `<input type=file>` в WebView2, буфер обмена.
